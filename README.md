* Bachelor Thesis project — designed and implemented a hybrid recommendation system for Steam games, combining content-based filtering (TF-IDF vectorization and cosine similarity) with market-popularity metrics
* Collected data for over 82,000 games using the Steam Web API and SteamSpy API, including metadata, descriptions, ownership, and popularity
* Built a text preprocessing pipeline with HTML tag removal, language translation, stop word elimination, and lemmatization
* Deployed the system through an interactive Streamlit web interface delivering personalized recommendations in real time
